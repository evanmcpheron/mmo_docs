# Review and execute a ticket

Read AGENTS.md and README.txt from this repository. Resolve the ticket in sources/development-roadmap.json and inspect its exact parent criteria, prerequisites, scope, exclusions and gameplay references. Use guide/unreal-cpp.html and guide/networking.html for the Unreal Engine 5 C++ foundation and authority requirements.

No implementation location is currently designated. Do not create a game project here, infer a code location or manufacture runtime evidence. A request to implement gameplay requires the owner to establish the implementation workspace in that future task. Complete independently authorized documentation work and report the missing implementation context accurately.

When actual execution becomes possible, preserve stable IDs and canonical contracts, execute positive and failure-path checks, and record tested revisions and actual artifacts separately from authored specifications. Update only verified status and evidence in the registry, reconcile dependent epic/milestone states, then regenerate and validate using README.txt. Documentation checks never complete a gameplay ticket.
