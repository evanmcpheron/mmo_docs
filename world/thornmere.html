Original design target

Hub: Thornmere village. Landmark: The Split Bell, a cracked signal bell over the village square.

Intended map: L_ThornmereVillage. This is an authored design target, not a supplied or generated Unreal map.

Geography and return travel

Thornmere ↔ Elderwood; Elderwood is the onward gateway

Each transition declares destination ZoneId, safe SpawnId, capacity/reservation policy, gate eligibility and a tested return path. Essential travel must not require a particular combat discipline or another human online.

Resource and vocation opportunities

Common ore, small private gardens, Reedbank fishing pools, salvage from old farm walls

Learn the creator/vocation/mentor flow, choose an outing, prepare a useful product and make the first durable contribution.

For each opportunity provide a base-proficiency or NPC commission alternative. Advanced specialist variants add control and identity, not exclusive critical ingredients.

Quest arc

First Supplies → A Sound from the North → Watchtower at Dusk

Use personal quest graphs that observe authoritative objective receipts, with a separate realm-stage condition for public services. A late-arriving character can still complete their personal arc after shared development is finished.

Production recipe

  1. Acquire or author licensed terrain, interior, prop, creature and effect art; record exact source paths and hashes before importing.
  2. Create ground/obstacle/overhead tile layers, collision and matching walkability cells. Validate arrival/return cells before decorating.
  3. Assign stable region, zone, site, NPC, quest and discovery IDs in DA_GameCatalog. Place service/gather/water/encounter actors only at authored eligible cells.
  4. Author development-stage visuals plus danger variants. Bind all consumers to the same snapshot revision, not local map-load reward logic.
  5. Complete the local vocation/quest loop alone, then run the two-client stay/transfer and shared-state tests.
  6. Profile the new region at relevant populations; run content migration/reconnect tests before adding another biome.

Acceptance and missing detail

Every biome still needs full item/recipe/quest instances, authored tile/collision geometry, enemy/FX/audio art, complete NPC dialogue and actual runtime testing. These pages define original geography and reproducible production responsibilities; they do not claim six playable zones.
