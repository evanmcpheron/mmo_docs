For remote or durable behavior, use the Phase 04 dedicated process baseline and Phase 06 transaction/lease boundary once active. Earlier fixtures are explicitly disposable, not production services.

Editor and configuration sequence

Add WatchFitting recipe and forge service. Build the small North Road project schema, board and record now because this phase requires a real repair outcome. Connect prospect → salvage encounter → harvest → forge → watchtower contribution.

Create native types in the future game repository, compile the applicable Editor target, then reopen the Editor before choosing custom Blueprint parents. Add/assign only the data and components named by this phase. Save the assets and configured route map. Exact menus/APIs that require the missing installed version remain an Unverified integration.

Faction extension: Retain early project board and one region owner. Prepare faction-neutral bound work receipts alongside the existing Forgekeeper fitting route; do not claim the full campaign or all five recipes exist.

Native ownership contract

Crafting and contribution share receipt/transaction primitives. The early project is not a debug counter: debit inputs, record contribution and publish stage once. Expand this same owner/schema at 22/23.

All custom signatures in linked pages are proposals. BlueprintReadOnly exposes state for observation; BlueprintCallable exposes a request path, not authority. Definitions remain immutable during play.

Reopen existing consumers and wire the feature

WBP_Crafting; WBP_RegionBoard; ARegionProjectionActor; DA_Project_NorthRoad; DA_Quest_FirstSupplies

Initialize identity/lease and load the applicable definitions before enabling commands. Construct local widgets, bind to change notifications, then pull the current snapshot. Apply only newer revisions. Cancel/unbind on teardown and ignore late callbacks for an old body or connection generation.

Develop the connected route fixture

Use L_ThornmereVillage → L_ElderwoodRoad → Thornmere as the recurring integration route. The preview map is the dedicated exception for visual import tests. Use explicit stable account/character/site/quest/project IDs from the linked system chapter.

Test values are fixtures. Reset only a named development realm or isolated test record set; never erase an existing user realm to make a test pass. No future asset or service is claimed present now.

Faction acceptance: One character can contribute through basic work; race duplicate source IDs and existing NorthRoad alias.

Run now and capture observations

As a solo Forgekeeper obtain 3 ore and 1 salvage plate, forge one fitting and contribute it. Inspect inventory debit, mastery and region receipt; restart and observe the repair state.

For shared-state phases run one human on a dedicated server first, then two separate clients. For relevant contention features repeat at 5, 10 and 30 connected clients and record the environment. Early visual-only phases defer remote checks to Phase 04.

Success, rejection and regression

Double-click craft, replay contribution, lose response after commit and fill inventory all have explicit outcomes. No animation completion may grant fitting or stage credit.

Rerun vendor alternatives so another vocation can acquire essential fittings without a human blacksmith. Maintain the same catalog/region identities through later phases.

Capture before/after IDs, revisions, amounts and expected error codes. A command that lost its response must retain its original request identity for reconciliation. Record Not run instead of manufacturing an observation.

Scope, maturity and stop condition

Documentation status: initial implementation recipe. Game/runtime status: not implemented or tested by this package. The full per-property and engine-specific wiring demanded by the master prompt is not yet complete for every planned asset.

Stop if an ordinary player cannot reach the new feature, a required reference is missing, a rejection mutates durable value, or a test depends on unverified art/API behavior. Do not mark the phase complete because its page or classes exist.
