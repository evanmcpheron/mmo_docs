Actor

A live object in a world, such as a creature or resource site. Destroying it must not erase a durable record.

Pawn / Character

A controllable body; Character adds movement-oriented engine facilities. Neither is the account database.

Component

Reusable behavior attached to an Actor. Use it for a focused responsibility, not a duplicate model.

Interface

A shared callable contract for otherwise unrelated types. It does not create authority or storage.

GameMode

Server-only rules/admission for the current world.

GameState

Replicated public state for the current world, not a durable cross-server database.

PlayerController

Owned input and command/UI routing. Validate gameplay requests server-side.

PlayerState

Replicated per-player runtime state; privacy depends on which fields are sent to which connections.

GameInstance

Process-lifetime coordination across ordinary local travel. Each process has its own; it is not shared realm truth.

Server RPC

A client-to-server request through an owned network object. It is not evidence that its payload is valid.

Replication

Server-selected state sent to appropriate clients. Persisting and replicating are different operations.

Prediction

Permitted temporary client response before server confirmation, with correction/reconciliation.

Data Asset

Authored immutable definition data. A recipe definition is not the player’s learned-recipe record.

Item instance

One owned item identity/quantity and mutable properties, distinct from the shared item definition.

GAS

Gameplay Ability System: attributes, abilities, effects and associated execution/prediction mechanisms, not MMO persistence.

Gameplay Tag

A named vocabulary entry used in definitions/rules, not a permission bypass.

Flipbook

A Paper2D sequence of sprite frames and durations.

TileSet / TileMap

An atlas-derived tile definition and an arrangement of tiles/layers. Walkability and collision still require setup.

PaperZD

Third-party 2D animation tooling. Exact installed APIs and overlay synchronization require verification.

UMG focus

Which UI control receives keyboard/controller actions. Opening a widget does not pause the multiplayer world.

Transaction

An atomic change whose related deductions, grants and receipt either commit together or do not.

Idempotency

Repeating the same semantic request identity returns its original outcome without repeating its effects.

Receipt

Durable evidence of the accepted command and result, written atomically with that result.

Domain uniqueness

A separate invariant such as one catch per CastId, even when a malicious client uses different request IDs.

Session lease / epoch

Time-bounded authority for one server to act for a character; an increasing epoch rejects stale owners.

Zone transfer

A coordinated change of authoritative gameplay server for one character, not a whole-server map change.

Content migration

An explicit versioned mapping of stored IDs/values to a changed supported schema/catalog.

Contribution meter

A view of committed project progress, not a counter that the widget may increment authoritatively.

Accessibility alternative

An equivalent usable interaction mode, such as forgiving fishing timing, with the same server validation.

Outbox

Durable delivery work saved with a transaction so committed changes can be projected after a crash.

Planned game behavior is not runtime evidence. Read sources and limitations.
