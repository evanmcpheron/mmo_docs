Read offline

Extract the entire ZIP and open index.html. Keep the directories together. Search, filters, navigation and progress export/import do not require a web server. External sources are optional reference links, not runtime dependencies.

Direct-file and local-HTTP browser navigation were blocked by this environment’s policy. The delivered design uses relative files without network dependencies; isolated rendering/control tests are recorded separately.
