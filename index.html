Readiness and evidence

This is a comprehensive mechanics design, not a playable Godot project. Numerical profiles and representative item recipes are prototypes. Structural, progression, arithmetic and offline-browser checks are distinct from runtime implementation, balance, economy and capacity testing.

Structured data and reuse

The same package includes versioned JSON catalogs, sample valid allocations and a repeatable Python validation script. They are design inputs, not an executable combat engine.
