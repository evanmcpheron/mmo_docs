Purpose and ownership

Four-facing baseline idle playback; no angled frame claim.

Owner: Content author; immutable during play. Lifetime: Loaded content; no player state.

Replication: None for authored definitions/assets. Persistence: Save stable IDs only; not this object.

Authored values describe rules; runtime projections and persistent instances remain separate. A view/definition cannot become an additional authoritative writer.

How to create and configure

Do not fabricate an import. Locate the licensed source and creator settings first; fill the missing source-path/frame/pivot/direction evidence. Follow the import/facing procedure and verify all layers before marking art present.

Enable Paper2D through Edit → Plugins and restart. Import only a locally licensed source sheet into Content/Game/Art/Characters after recording archive and file hashes.

Commands and notifications

No executable command is supplied on this definition/view contract. The owning system chapter specifies the future validated operation and observable result.

Custom project functions and backend endpoints are proposed. Engine creation actions, plugin APIs and these custom commands are not interchangeable. Emit a completed-change notification only after the owning rule/transaction succeeds.

Lifecycle, failure and recovery

Reject an invalid or expired lease, an unknown content ID, a stale revision, insufficient capacity or permission before mutating state. Return a stable error code and refresh the current projection; do not ask the player to repeat an unknown-outcome transaction with a new request ID.

Persist the operation receipt in the same transaction as its effects. On a lost response, query or retry the same request identity. A successful receipt returns the original result; a changed payload under that identity is rejected. A UI timeout is not proof of a database rollback.

For a definition, do not attach a transaction/RPC to the Data Asset itself: its owning runtime service implements this lifecycle. For presentation, bind once, pull the snapshot and unbind on teardown; ignore stale callbacks.

Concrete wiring and fixture

L_BriarwakePreview contains one body, one outfit and each independently supported optional layer, viewed from North/East/South/West. Source sheets and frame counts are currently unavailable.

Receive server-approved appearance IDs, action type, facing and action start time.

Play cosmetic notifications only. Stopping playback, suppressing notifies or hiding the character cannot change authoritative rewards.
