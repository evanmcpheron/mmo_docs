Phase objective and completion

Create the blank UE5 C++ client/dedicated-server baseline, verify the supplied replication plugins and C++ boundaries, then run independent fixture, content, durable-store and 3D pixel-art feasibility probes.

0/7 complete · 0%

Phase status: Not Started. Complete only when all 7 epics below are Complete with verified evidence.

Native builds and actual player-free startup, supplied-plugin compatibility and negative probes, attributable automation, reviewed content import, real-store retry/crash recovery and measured Unreal camera/material feasibility all have fresh evidence. No documentary review certifies these outcomes.

Integrated completion milestone: Verified Unreal C++ foundation and ownership proof. Its full prerequisites and integration evidence must also pass; individual components do not prove their integration.

Hard dependencies are required for completion. Recommended predecessors are scheduling preferences. Other phases are not global start barriers. How to read this roadmap.

Epics in this phase

  1. BW-001 · Reproducible native Unreal C++ client and dedicated server Not Started Dependency-ready

    Create a blank native Unreal Engine 5 C++ project and prove reproducible client/server build and startup outcomes.

  2. BW-002 · Authority boundaries and content admission Not Started

    Make documented state ownership and enabled-content compatibility enforceable boundaries.

  3. BW-100 · Verify owner-supplied replication plugins Not Started

    Establish the actual compatibility, capabilities and authority boundaries of the already acquired replication plugins before dependent network implementation.

  4. BW-003 · Repeatable runtime fixtures and diagnostics Not Started

    Produce attributable runtime evidence from the first experiments.

  5. BW-097 · 3D pixel-art renderer and camera feasibility proof Not Started

    Prove the selected real-time 3D pixel-art direction in a pinned Unreal Engine 5 build before producing assets in volume.

  6. BW-095 · Versioned content authoring and import workflow Not Started

    Make documented content producible and reviewable through the same contracts used by runtime admission.

  7. BW-018 · Durable ownership and mutation recovery probe Not Started

    Prove economic consistency before building asset-dependent features.

Open an epic for its full scope, dependencies, acceptance criteria, verification and ticket planning.

Direct prerequisites from other phases: None
