Phase: 1. Native C++ foundation and technical risk verification · Completion milestone: Verified Unreal C++ foundation and ownership proof

Objective and scope

Create a blank native Unreal Engine 5 C++ project and prove reproducible client/server build and startup outcomes.

Scope: Pin a compatible UE5 engine source/distribution revision, compiler/SDK and host/target matrix; create the blank C++ runtime module and Game/Editor/Server targets, then build, cook, stage and launch isolated client and dedicated server artifacts. Excludes gameplay, replication-plugin integration, bulk assets and production hosting.

Acceptance criteria

  1. AC 1

    A clean environment creates and builds the blank native UE5 C++ client and dedicated Server target using recorded engine source/distribution, compiler/SDK and target-platform revisions; build/cook/stage steps and input/artifact identities are reproducible without copied caches.

  2. AC 2

    The server starts without graphics or a local player and reports its build, rules and content revisions.

  3. AC 3

    Missing required configuration fails with an actionable diagnostic; credentials are absent from distributed client artifacts.

  4. AC 4

    A clean automated run distinguishes build failure from an executed passing or failing runtime check.

Verification and blockers

Completion evidence required: Exact engine/toolchain/target matrix, C++ module/target configuration, clean build/cook/stage logs, artifact hashes, actual client launch and player-free dedicated-server smoke, plus configuration/secret-exclusion and automation failure controls.

Recorded evidence: None. Required evidence above describes future verification.

Blockers: None recorded; see hard prerequisites.
