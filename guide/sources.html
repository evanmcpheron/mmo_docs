Research boundary

External sources inform engine capabilities, database guarantees, intellectual-property caution and the profession reference. The rules, formulas, faction exclusivity, talent structure and profession recommendations in this package are original design proposals, not claims that Blizzard or Godot recommends these exact mechanics.

Sources were checked on October 16, 2026. Documentation under stable or current may change; pin a specific tested Godot and PostgreSQL release during implementation.

Intellectual-property limits

Traditional archetypes and a two-faction structure do not make reproducing another game's specific creative expression safe. Use independently created ability descriptions, art, icons, sound, visual identities and branding. Race, faction, class and ability names in this prototype have not received a trademark clearance search. This reference is not a legal clearance opinion. Obtain appropriate review before committing to commercial branding or asset production. Sources S7, S8

Supplied v1 materials

The source was the attached MMORPG_Character_System_Design_v1.zip and its character catalog, plus the accompanying master/reference markdown files. The v2 package preserves stable identifiers for the inherited class, specialization, ability and talent inventory where possible. It changes progression, race/faction policy and implementation contracts explicitly.

The original package remains unchanged outside this output. V1 narrative text is not copied into the current mechanics reference. The data provenance file records source filenames and checksums so changes can be traced without mistaking old lore for current design.

How to read readiness labels

Design policy means a recommended governing rule. Prototype profile means explicit initial numerical parameters, not proven balance. Shared rule contract means a repeatable talent behavior has been specified, but still needs runtime code and tests. Bespoke binding required means an entry's named special behavior has not yet been resolved into certified runtime operations. Validated always refers to a named structural/arithmetic/browser check, never a blanket endorsement of game quality.
