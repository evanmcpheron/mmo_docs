Mechanics glossary

Mechanics, governing rules, edge cases and acceptance criteria.

Term Meaning in this reference
Ability A server-validated active or passive action with a stable definition ID
Action ID Unique request identity used to recognize retries and prevent duplicate execution
Adaptive primary One equipment attribute line that resolves to the current specialization's primary stat
Aggregate budget One total output allowance shared by effects, songs or summons; adding recipients or entities does not automatically add new budget
Area of interest The set of world entities/effects relevant to a client's location and permissions
Attribute Strength, Agility, Intellect, Stamina or Spirit
Band One of six character/profession progression ranges; not a geographical region
Baseline role kit Mandatory tank/healer functionality provided independently of optional talents
Binding Item transfer restrictions, or—in content engineering—the conversion of a design rule into executable operations; context distinguishes them
Capstone A late-tree mutually exclusive playstyle choice, not a requirement for a specialization to function
Class Permanent character archetype such as Warrior or Bard
Class point One of 59 points available only to the shared class tree
Combat power The derived scalar P used by authored damage/healing coefficients
Commission Crafting for another character using server-reserved materials and durable delivery
Content version The exact revision of ability, talent, item and recipe definitions used by the simulation
Crowd-control DR Diminishing returns reducing repeated control effects in a category
Damage debt Deferred damage still owed by the recipient; not absorbed or prevented damage
Effect An explicit operation such as damage, healing, dispel, movement or a bounded summon
Equipment budget Allowed stat/effect allocation for an item level, slot and grade
Escrow Items or currency reserved for a transaction without becoming available for competing uses
Faction Good-aligned or evil-aligned eligibility/relationship field; no narrative is specified
GCD Global cooldown shared by applicable actions
Grade Standard, Refined, Masterwork or Challenge item-budget multiplier
Idempotent Repeating an already-processed request does not apply its effects again
Mastery rating A combat secondary stat improving a declared specialization output family
Profession mastery Separate profession talent progression; not combat Mastery rating
Normalized weapon damage Two seconds of allowed equipped weapon DPS for ability coefficients
Outbox Durable records of events created with a committed transaction and delivered afterward
Owner epoch Version of authoritative ownership used to reject stale commands after transfer
Personal output Damage/healing attributable to the character's own effects before separately credited support
Profile A reusable prototype timing/cost/effect definition; not necessarily an entire named ability
Race One of 11 ancestry selections with fixed starting stat offsets; Human supports both factions
Resource Mana, Energy, Rage, Focus, Cadence or a bounded signature meter
Role Tank, Healer or DPS; support is an important secondary characteristic
Skill point In the character progression request, a class or specialization talent point; profession skill increases separately
Specialization Selected role and mechanical discipline within a class
Specialization point One of 59 points available only to the selected specialization tree
Stack group Category defining whether effects coexist, refresh, add or select the strongest
Talent Optional ranked modifier or mutually exclusive transformation inside a tree
Ward Unified initial magical-defense statistic, avoiding multiple mandatory resistance sets
