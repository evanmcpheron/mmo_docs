Not Started · Parent epic: BW-002 · Authority boundaries and content admission

Epic acceptance criteria: BW-002-AC-5

Implementation scope

  • Extend the existing admission owner with an economic graph check only after T05 resolves and publishes its canonical inputs. Consume its reviewed item/material identity and original-input provenance rules. Cover the complete requested enabled vendor purchase/sellback, crafting, material conversion and salvage graph, including paths crossing several records and already enabled dependencies; do not certify each recipe independently.
  • Use explicit guaranteed costs/quantities and currency minor units with checked arithmetic. Honor crafted sellback strictly below guaranteed NPC-purchased input cost, material loss on craft/salvage, at most 25% eligible common returns, zero rare/bound component return and zero salvage gold/XP. Distinguish guaranteed repeatable paths from random output or finite supplies; missing price/mapping/provenance/required quantity prevents affected route activation. No inferred market-price oracle or default zero.
  • Implement a finite deterministic analysis whose soundness and supported graph bounds are documented. If the analyzer cannot prove the gate for a supported request, return an actionable finding and keep the candidate disabled; a search timeout or partial traversal never certifies safety. Keep graph derivation internal to admission, not a new canonical economic framework.
  • Commit positive loss-making and negative profitable/self-amplifying multi-route fixtures, combination-only loops, alternative recipes, quantity rounding, equal-cost crafted sellback, salvage/provenance failures, missing values and overflow/bound exhaustion. Check whole-candidate atomicity, including a harmless route whose combination with prior enabled routes becomes unsafe. A positive graph pass is admission certification only; gameplay economic handlers still require independent implemented support.

Out of scope

  • Vendor UI, crafting execution, actual currency/item mutation, production balance, player-market arbitrage restrictions, database settlements or proving server capacity.
  • Treating all economic routes disabled as a substitute for the required positive/negative complete graph demonstration.

Dependencies

Hard prerequisites: BW-002-T03, BW-002-T05

Acceptance criteria

  1. AC 1

    A fully specified safe synthetic graph passes the graph gate; a graph with an unlimited guaranteed gain is rejected with implicated routes/IDs before activation, including gain discoverable only through combined routes.

  2. AC 2

    Crafted sellback equal to or above guaranteed NPC input cost rejects; salvage exceeds neither eligible common provenance nor 25%, yields no rare/bound components, gold or XP, and cannot create unbounded profession advancement from starter supplies.

  3. AC 3

    Missing prices, identity links, provenance or quantities and unsupported/overflow/bound-exhausted analysis reject visibly. Explicit zero is distinguished from absent input; no sampled or timed-out analysis returns success.

  4. AC 4

    Rejected graph replacement leaves the full active selection/revisions unchanged. Deterministic results and positive/negative controls exercise the real native gate under T05 canonical contracts without enabling absent gameplay handlers.
