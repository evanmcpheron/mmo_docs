In Progress · Parent epic: BW-095 · Versioned content authoring and import workflow

Epic acceptance criteria: BW-095-AC-1, BW-095-AC-2

Implementation scope

  • Extend the same extraction/admission route only for the bounded world/tutorial relationship closure: ZoneDefinition, WorldLocationDefinition, ZoneTransitionDefinition, RecoveryPointDefinition, StarterAreaConfiguration, TutorialSequenceDefinition, quests/objectives/rewards, guide instructions and referenced interaction/service definitions needed by the representative sample. Reuse T04 NPC/encounter links and canonical progression. These are missing native static integrations, not a request to build a playable starter area.
  • Validate zone/location/floor/transition ownership, protected-location subsets, recovery/service and starter faction references, quest prerequisite reachability and required/optional separation. Tutorial stages must occur exactly once in arrival/first_growth/more_choices/putting_it_together/graduation order with canonical bands 1–2/3–4/5–6/7–9/10. final_challenge_ids must exactly index tank/healer/dps role challenges.
  • Implement required_solo_path_to_ten_v1 as one native admission check: starting at level-one zero XP, count each required one-time quest reward and distinct required encounter completion_experience once against the canonical level-ten threshold before final challenge; exclude optional tasks/encounters, profession rewards and repeated practice. Require explicit reviewed amounts; missing XP/content rejects rather than inventing rewards. Validate authored class/ability unlock relationships statically; actual solo playability remains with starter/feature epics. Add focused valid and rejected relationship/XP cases using the existing test harness.

Out of scope

  • Starter map construction, NPC placement, narrative/localization production, movement/transfer/recovery execution, quest rewards and human solo-play certification.

Dependencies

Hard prerequisites: BW-095-T03, BW-095-T04

Acceptance criteria

  1. AC 1

    The bounded linked world/tutorial sample round-trips through the shared route with exact content IDs and valid package/zone/faction/floor/service relationships.

  2. AC 2

    Foreign locations/transitions, missing services, cyclic/unreachable quests, wrong/duplicate stage order, overlapping required/optional sets and mismatched role-challenge indexes yield record-level findings and atomically reject.

  3. AC 3

    The required path reaches the canonical level-ten XP threshold before final challenge using only eligible one-time required rewards. Missing values, double counting or reliance on optional/repeatable rewards reject; static checks imply no executed playable journey.
