Never rewrite the reference

No writes were sent to game_docs. The new guide uses original text, structures and design contracts rather than republishing an entire source repository. Audit the remaining source pages before claiming exhaustive migration coverage.

Native implementation standard

Use descriptive names, explicit invariants and small cohesive components. Prefer composition over a universal Actor superclass. Server transaction primitives are shared across crafting/quest/economy/project changes, while actual domain validation remains readable and separate.

Planned game behavior is not runtime evidence. Read sources and limitations.
