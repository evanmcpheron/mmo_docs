Reference only, not a source game

Briarwake is an original 2D pixel-art fantasy MMORPG being developed from the ground up in Unreal Engine 5.8.3. The existing Briarwake Unreal repository is the development starting point. No previous game implementation, port or conversion is required. Earlier game_docs material is optional historical and engineering reference. Each phase introduces or extends Briarwake’s own systems; planned contracts are not runtime evidence.

game_docs was consulted for documentation organization, technical guidance and reusable engineering principles. Briarwake’s requirements and gameplay architecture are its own. Old Blueprint names below are examples, not objects to locate, import, convert or remove. No old player profile, save, movement system or asset pack is required. The existing source-migration.html URL is retained for link compatibility; its label is historical, not an onboarding task.

Preserved technical migrations

Schema upgrades, versioned character/vocation/faction records, content-ID aliases, deployment transitions and fenced zone transfers within Briarwake remain required. These preserve this game’s own data and authority; they do not imply a port from game_docs.

Publication and history boundary

Only mmo_docs is corrected. The historical game_docs site, including its assets/Core/RPG.html page, is published from a different repository and remains unchanged. Its incomplete historical comparison is optional background, not a blocker to normal Briarwake development. MASTER_PROMPT.original.md and earlier verification records remain preserved.
