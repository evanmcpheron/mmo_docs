Multiplayer

Operations, recovery and population testing

Treat durability failures as state reconciliation problems, not user-interface retries.

Design contract

Controlled environments

Keep development, test and production identities/configuration separate. Credentials belong in environment-specific secret storage, never client packages, this manual or logs. Provider choice and concrete deployment automation require a separate verified implementation.

Backups and migrations

Version records and content catalogs. Rehearse restoring a backup into an isolated store, replaying only supported committed receipts/outbox work and validating inventory/region/session consistency. Record recovery point and recovery time from an actual rehearsal. Backing up without restore testing is not a recovery proof.

Failure matrix

FailureRequired observable behavior
Database unavailable before commitReject or retain a known pending operation; do not display a durable success.
Response lost after commitResolve same receipt without repeat debit.
Zone crashExpire/fence the old lease, admit one recovery session.
Stale content versionReject or migrate through a versioned reviewed map; do not silently reinterpret IDs.
Partial deploymentMatch compatible zone/client/content versions or deny admission cleanly.
Malicious request floodRate-limit by authenticated scope, log bounded diagnostics and preserve unrelated players’ progress.

Population fixtures

Run 1, 2, 5, 10 and 30 actual connected clients with active combat/gather/vendor/region/social/travel interactions. Record hardware, build SHA, connection count, latency/loss, scenario duration, server CPU/frame time, network traffic and persistence command latency. Budgets are proposed only after a baseline is measured.

Privacy and moderation

Document block/report flows, permission checks, account bans and admin audit. Avoid public account IDs, inventory contents, tokens or private chat in replicated state/logs. Data retention and deletion policy require decisions appropriate to the actual service; this manual does not supply legal compliance certification.

Runtime evidence
