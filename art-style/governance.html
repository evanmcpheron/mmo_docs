    Source of truth

    sources/art-bible/chapters.json owns guide prose and chapter records. palette.json owns named colors and ramps. create_art_references.py owns reproducible original drawing recipes; scene-maps.json and references.json are generated evidence. tools/art_manual.py supplies narrowly scoped rendering helpers to the existing manual generator. Published HTML and search data are generated output.

    Do not edit generated HTML alone. Rebuild the Art Bible and the whole manual through build_manual_indexes.py as appropriate. An art-only mode supports focused authoring in a partial workspace; it does not replace full-repository checks before publication. Preserve historical master sources unchanged.

    Owner decisions and migration

    A new master palette, character proportion system, density rule or fundamental tileset convention requires explicit owner approval. Record proposed revision, affected categories, rationale, comparison images, migration/remap instructions and rollback path. A commit or PR approval that does not name the visual decision should not be treated as implicit art approval.

    This assignment explicitly selects Godot/Aseprite for the new art pipeline. It does not authorize conversion of game code or gameplay architecture. Networking, world state, combat and equipment ownership remain with their existing gameplay systems.

    Version 0.1.0 — 15 October 2026

    Initial Art Bible review edition: foundational scale and pixel rules, ten terrain families with complete binary transition sets, reusable village and regional maps, original layered eight-facing walk study, material palette, production handoffs, local viewers and validation. All new colors and art remain proposed or technical demonstrations.

    Supersedes Unreal/Paper2D/PaperZD preparation instructions for new art only. Migration for artists: preserve existing asset filenames; retain old source archives privately; prepare editable Aseprite sources and explicit PNG/JSON exports. No game assets are renamed, converted or modified.

    Open decisions

    Owner approval is pending for Study 01 palette, detailed body measurements, tree and building study proportions, region kit appearance and all new original images. Team patch-version adoption, logical resolution, camera/snap policy, terrain peering mapping and final animation resource strategy require technical decisions and runtime tests.

    Legacy paid asset rights, AI-workflow terms, exact race anatomy, creator layers, sheet dimensions, running conventions and recommended durations remain unverified because the inspected game tree contains no such assets or license documents.
