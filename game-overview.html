Briarwake · game overview

An entirely 2D persistent-world action RPG whose essential PvE progression remains available to one human.

The player promise

Committed requirement: combat, exploration, dynamic chosen professions, world development and social play are comparable pillars. A quiet server must still support the complete required PvE adventure, vocation mastery and critical regional improvements. More people add cooperation, variety and recognition rather than mandatory dependencies.

What the game is

Briarwake uses a fixed three-quarter top-down pixel-art presentation, X/Y movement input, authored 2D tile layers and loading transitions between bounded zones. Initial facing art is four-direction; eight-way movement does not imply eight-direction sprites. Sprint, dodge, a short eligible-obstacle hop and swimming are committed. Climbing, platformer precision traversal, 3D terrain and camera rotation are not.

Two independent identities

Each playable character must choose exactly one primary vocation: Forgekeeper, Hearthkeeper, Wayfinder, Woodwright or Apothecary. All characters can fight, explore, harvest basic materials and use baseline NPC services. Vanguard, Ranger, Arcanist and Warden describe proposed combat disciplines, not replacements for vocation choice.

The recurring route

Begin in Thornmere village, meet a mentor, choose an outing along Elderwood Road, encounter a threat or use a calmer investigation route, obtain and transform useful materials, and contribute to the North Road repair. Returning players see the committed bridge/watchtower state and newly available services. That same route receives the features in Phases 00–31.

What exists in this delivery

An offline documentation site, source registries, source-preserving requirement coverage, deterministic generators, validators and arithmetic/design tests. No Unreal game project, runtime C++ implementation, sprite pack, third-party plugin, server binary or database has been generated. The full master-prompt acceptance contract is not yet satisfied.

Explicitly deferred

PvP, conquest, taxation, player political governance, player housing, auction houses, unrestricted terrain modification, endless procedural worlds and massive mandatory raids are not part of the committed baseline. Scaling beyond the initial 1–30 test population requires measurements.
