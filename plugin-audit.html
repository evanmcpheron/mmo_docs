Recommended decision

Retain the plugin as an instructional prototype and possible local session bootstrap, subject to inspection. UConnectionSubsystem exposes one narrow connection route; it does not run a second competing session manager. Production admission and persistence do not depend on menu state.

Proposed adapter sequence

Idle → Searching → ResultsReady → Joining → ResolvingAddress → Connecting
Idle → DestroyingExisting → Creating → Hosting
Any pending state → explicit failure / cancellation → Idle
Dedicated advertisement: separate server-owned path, no local-player dependency

Actual audit procedure

  1. Keep the original ZIP outside this repository. Record its SHA-256 and a complete relative-path inventory.
  2. Read the descriptor, Build.cs, public headers, subsystem methods and Menu.cpp with stable line numbers. Inspect menu asset behavior in the actual compatible Editor; a binary filename does not reveal its graph.
  3. Replace each reported finding with confirmed / disproved / changed evidence and exact path:line ranges. Read licensing separately; attribution alone is not redistribution permission.
  4. Compile against the actual target engine and installed provider. Record compiler output without discarding warnings, then package server and two client processes.
  5. Run the listed error, callback, menu lifetime and dedicated cases. A successful source audit is not a successful build or live join.
