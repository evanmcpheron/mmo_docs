Talent contract

Each node declares a stable ID, point cost, prerequisite node IDs, exclusive branch group where applicable, granted ability/effect ID and respec policy. Purchases validate budget and prerequisites in the service; the zone rebuilds permitted GAS grants from the committed build revision.

Suggested first meaningful choice is between a defensive utility and a situational damage/control tool, not dozens of indistinguishable percentage bonuses. Exact nodes, level tables and complete class balance are still to be authored.

Creator and tutorial

Committed requirement: choose exactly one available combat discipline during character creation and store its stable DefinitionId as CombatDisciplineId. This combat class is permanent. Every available class supports every vocation and valid faction; no vocation change changes class, combat XP/level, abilities or purchased combat talents. Respec only redistributes talents within the existing class under its current policy.

Introduce a basic art-supported combat action in the tutorial and let the player learn the difference from vocation. The prototype may offer only currently integrated disciplines. Final-system documentation still owes all four specified skill trees and their tested solo paths.

Rebuild and respec tests

Respawn, equipment swap, travel, reconnect and respec must not duplicate attribute modifiers or ability grants. Remove old grant/effect handles and apply the new validated build once. Never write independent cooldown logic inside ability-bar widgets.

GAS boundary

GAS is the recommended framework for attributes, abilities, effects and cooldowns after installed-version validation. Quest rewards, persistence, crafting, professions, party membership and realm allocation remain separate explicit responsibilities.

Independent combat progression and write protection

Record_Character.Progression.Combat owns combat TotalXP, pinned DefinitionVersion, purchased talent IDs and unspent combat points. Derive level from its validated curve, not vocation level; Combat 40 / Forgekeeper 5 and Combat 10 / Hearthkeeper 30 are valid unless a particular authored activity explicitly states a requirement. Vocation mastery points cannot buy combat talents.

Reject any post-creation CombatDisciplineId mutation at the authoritative durable boundary, including a generic record update or forged client payload. No class-change NPC, reset token, alternate active class or multiclass system is introduced. Returning to a vocation restores only that vocation’s progression; class grants remain associated with the permanently selected definition.
