Open and navigate

  1. Extract the entire ZIP to a normal local folder. Open index.html directly in a desktop browser; keep site/, assets/, systems/, phases/ and sources/ together.
  2. Read the evidence/status panel before beginning Phase 00. Search works from a generated local JavaScript index and does not require a web server.
  3. Open the roadmap, select the current phase, read its linked system and asset pages, then perform creation/configuration/integration in the future game repository—not inside this documentation repository.
  4. Capture actual Editor/build/runtime logs and observations on the development machine. Checklists track your local progress only; they do not change the shipped verification record.

Completion is a separate gate

The default checks verify the delivered partial package is internally accounted for. python tools/check_feature_coverage.py --require-complete intentionally fails while implementation-detail coverage or required input audits are incomplete. Passing local HTML checks does not pass the game’s phase acceptance tests.

Planned game behavior is not runtime evidence. Read sources and limitations.
