Documentation problems

Run the generators, then validators from repository root. For broken relative links keep the extracted directory intact. For browser storage limitations export progress JSON; localStorage is best effort. Search uses packaged JavaScript and does not require a server.

Escalation evidence

Include the phase, fixture IDs, expected/actual revisions, request/receipt IDs, build/content version and steps to reproduce. Redact tokens, personal data and paid art. Record source-only, compiled, packaged and runtime evidence separately.

Faction recovery and diagnostics

FactionUnavailable: refresh available catalog, retain disabled option explanation; do not substitute Hearthward. UnknownOutcome: retain RequestId and query receipt. MigrationRequired: use explicit owner confirmation for missing legacy faction; corrupt non-null identity requires review. InvalidSpawn/ContentVersionMismatch: retain identity and enter safe authenticated recovery.

StaleLease after travel: source is fenced, not a signal to create another writer. Changed regional policy: resnapshot public view; do not overwrite the personal journal or undo construction. Missing full faction art is not permission to enable an unauthored future campaign.
